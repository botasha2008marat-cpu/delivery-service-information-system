# Жүйе диаграммалары

Бұл папкада жеткізу қызметінің ақпараттық жүйесіне арналған UML диаграммалары сақталады.

Негізгі диаграммалар:
- Use Case диаграммасы
- Activity диаграммасы
- Sequence диаграммасы
- Class диаграммасы
- ## Жобаның ағымдағы нұсқасы

Жоба әзірлеу кезеңінде. Жеткізу қызметінің негізгі процестері ақпараттық жүйе арқылы автоматтандырылады.
