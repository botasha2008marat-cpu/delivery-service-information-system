# Жүйеге қойылатын талаптар

## Функционалдық талаптар

1. Жүйе клиентке тапсырыс беруге мүмкіндік беруі тиіс.
2. Жүйе тапсырыстарды қабылдап, өңдеуі тиіс.
3. Жүйе тапсырысты курьерге тағайындауы тиіс.
4. Жүйе тапсырыс мәртебесін өзгертуге мүмкіндік беруі тиіс.
5. Жүйе жеткізу барысын бақылауды қамтамасыз етуі тиіс.
6. Әкімші пайдаланушыларды басқаруы тиіс.

## Функционалдық емес талаптар

1. Жүйе қолдануға ыңғайлы болуы тиіс.
2. Жүйе ақпараттың қауіпсіздігін қамтамасыз етуі тиіс.
3. Жүйе пайдаланушы әрекеттеріне жылдам жауап беруі тиіс.
4. Жүйе деректерді сенімді сақтауы тиіс.
