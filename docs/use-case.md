# Use Case

## Жүйе пайдаланушылары

### Клиент
- Жүйеге кіру
- Тапсырыс жасау
- Тапсырыс мәртебесін көру
- Тапсырысты бақылау

### Курьер
- Жүйеге кіру
- Тағайындалған тапсырыстарды көру
- Тапсырыс мәртебесін жаңарту
- Тапсырысты жеткізу

### Әкімші
- Пайдаланушыларды басқару
- Тапсырыстарды басқару
- Курьерлерді басқару
- Жүйені бақылау

## Негізгі Use Case-тер

1. Тапсырыс беру
2. Тапсырысты өңдеу
3. Курьерді тағайындау
4. Тапсырысты жеткізу
5. Тапсырыс мәртебесін жаңарту
6. Жеткізу барысын бақылау
7. Пайдаланушыларды басқару
