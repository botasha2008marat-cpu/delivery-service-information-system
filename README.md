# delivery-service-information-system
Жеткізу қызметінің ақпараттық жүейсі

## Жоба туралы

Бұл жоба жеткізу қызметінің жұмысын автоматтандыруға арналған ақпараттық жүйені сипаттайды.

## Жобаның мақсаты

Жеткізу қызметіндегі тапсырыстарды қабылдау, өңдеу, курьерге тағайындау және жеткізу мәртебесін бақылау процесін автоматтандыру.

## Негізгі пайдаланушылар

- Клиент
- Курьер
- Әкімші

## Негізгі функциялар

- Тапсырыс беру
- Тапсырысты өңдеу
- Курьерді тағайындау
- Тапсырыс мәртебесін өзгерту
- Жеткізу барысын бақылау
- Пайдаланушыларды басқару

## Жоба құрылымы

- `README.md` — жоба туралы жалпы ақпарат
- `docs/requirements.md` — жүйеге қойылатын талаптар
- `docs/use-case.md` — Use Case сипаттамасы
- `docs/diagrams/` — жобаның диаграммалары
